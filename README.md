# Covirán Website

Recreación de la página web de **Covirán** realizada como proyecto académico.

> Proyecto realizado previamente para mi titulación de DAW y publicado posteriormente en GitHub como parte de mi portfolio.

## Tecnologías

- HTML5
- CSS3

## Características

- Cabecera con información de contacto y redes sociales.
- Menú de navegación con submenú desplegable.
- Sección principal con imagen promocional e interacción mediante CSS.
- Tarjetas de noticias con efecto hover.
- Secciones de servicios y colaboradores.

## Cómo ejecutar el proyecto

No requiere instalación ni dependencias. Abre `index.html` en un navegador web.

## Contexto

Proyecto académico de la asignatura Lenguaje de Marcas para mi titulación DAW basado en la recreación visual de la página de Covirán. El contenido y las imágenes se utilizaron con fines educativos.
